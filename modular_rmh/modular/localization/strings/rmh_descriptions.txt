# Описания этого билда: /тип/путь = русский; потомок без своего desc получает перевод родителя.
# Английский текст в ключе — только для того, что не принадлежит типу: что игра дописывает или задаёт в коде.
# Строки отсюда побеждают импортированные (descriptions.txt) при совпадении ключа.
#
# Ключ с "^" — шаблон для описаний, которые игра собирает сама: $1|nom, $1|acc и т.д. склоняют захват по словарю
# имён (items.txt, words.txt, titles.txt, rmh_items.txt). Словарь строгий: если захват не склоняется (имени нет
# в словаре), описание остаётся английским целиком, а не наполовину.
#
# Описание вида "[desc] Предложение." (начинки, качество готовки) отдельной строки не требует: игра переводит
# известное начало и каждое дописанное предложение по отдельности, если переведены все части.
# Род предмета здесь неизвестен, поэтому — безличные обороты, без прилагательных, согласуемых с предметом.
